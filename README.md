# Microsoft Learn Portfolio

## 專案簡介

本專案記錄本人透過 Microsoft Learn 平台進行 Azure 雲端技術自學的學習歷程。

學習內容主要來自 Microsoft Learn 官方教材及校方提供之雲端技能培訓資源，涵蓋雲端運算、人工智慧、資料分析及資訊安全等主題，並以 Microsoft Azure Fundamentals 系列證照知識體系作為學習方向。

## 學習收穫

透過 Microsoft Learn，我建立了對 Microsoft Azure 雲端平台的基礎認識，了解企業如何利用雲端服務進行系統部署、資料儲存、安全管理及人工智慧應用。

同時也培養閱讀官方技術文件與自主學習新技術的能力，並接觸產業常見的雲端架構與服務模式。
